# Intentional non-runtime archives

The original localStorage backup in this directory is retained as historical
evidence only. It is not shipped, imported, reconciled, or accepted by the modern
Planner restore service. It may contain personal application data; do not publish
this archive as a web asset or use it for production recovery.

Earlier Phase 3-6 reports, the owner-authored Phase 5 project identity crosswalk,
and Sheets/state/UI design notes in the parent spec directory are also
intentional historical documentation, not executable plans. Current architecture
and policies supersede their safe-mode/import/edit-only statements.
The generated Phase 5 reconciliation JSON and one-time Supabase exports were
removed; the historical summary retains its input hashes and aggregate findings.
