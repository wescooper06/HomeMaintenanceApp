# UI Screens

Historical planning inventory, not a current route manifest. Some proposed
screens were never implemented. See [current architecture](architecture.md)
and the [final route audit](final-modernization-health.md).

## Web Screens
| Screen | Data Needed | Actions |
|--------|-------------|---------|
| Trips Home | Trips | Open Trip |
| Idea List | Trips | Rank, Filter |
| Prioritization Table | Trips + Workflow Metadata | Rank, Edit |
| Annual Timeline | Trips + Month Constraints | Drag‑Drop |
| Trip Overview | Trips + Metadata | Edit, Open Tools |
| Resources Page | Resources | Add, Remove |
| Checklists Page | Checklists | Complete, Add |
| Itinerary Page | Itinerary | Add, Edit |
